# תחזית חיה · בחירות 2026

אתר סטטי (HTML + JS, בלי build) שמציג הערכה סטטיסטית בזמן אמת לתוצאות הבחירות לכנסת ה-26:
מנדטים לפי גוש, הסיכוי ל-61, רשימות על הסף ומעבדת תרחישים.

## מבנה

| ענף | תוכן | מי כותב |
|---|---|---|
| `main` | `index.html`, `vercel.json` — האתר עצמו | ידנית, לעתים רחוקות |
| `data` | `latest.json` (+ `vercel.json` שמכבה פריסות) — ההערכה האחרונה | הלולאה החיה של המודל, כל כמה דקות |

הדף טוען את `latest.json` מ-`raw.githubusercontent.com/Yedidiwah/-2026/data/latest.json` (כל דקה).
לכן נתונים חדשים לא דורשים פריסה: ב-Vercel (תוכנית חינמית) יש מגבלה של 100 פריסות ביום, ו-
`vercel.json` מכבה פריסות אוטומטיות לענף `data`.

## תצוגה מקומית

```
python -m http.server 8777
```

ואז `http://localhost:8777/` — הדף קורא מ-`data/latest.json` (תיקייה מקומית שלא נכנסת ל-Git).
אפשר גם `?data=<כתובת>` כדי לטעון קובץ אחר.

## מה לא בריפו

המודל, הטוקן של בוט הטלגרם ונתוני הבחירות נשארים מחוץ לריפו הזה. כאן יש רק את הדף ואת המספרים שהוא מציג.

האתר אינו רשמי. התוצאות הרשמיות: ועדת הבחירות המרכזית.
